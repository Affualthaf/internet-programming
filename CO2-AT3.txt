                <p>

                    works properly on mobile phones, tablets, laptops and desktop

                </p>

                <ul>
                    <li>Provides a better user experience on different devices.</li>
                    <li>Reduces the need to create separate mobile websites.</li>
                    <li>Improves readability and navigation.</li>
                    <li>Helps websites work with different screen sizes.</li>
                    <li>Improves accessibility and usability.</li>
                </ul>

                <h3>Key CSS Techniques</h3>

                <ul>
                    <li>Flexible layouts using percentages.</li>
                    <li>CSS Media Queries.</li>
                    <li>Flexible images using max-width: 100%.</li>
                    <li>CSS Flexbox.</li>
                    <li>CSS Grid.</li>
                </ul>

                <h3>Flexbox Example</h3>

                <p>
                    Flexbox can arrange elements in a row or column and allows

                </p>

            <h2>Question 2 – Client-Side Validation</h2>

            <div class="answer">

                <h3>What is Client-Side Validation?</h3>

                <p>
                    Client-side validation is the process of checking user input
                    in the browser before the data is sent to the server.
                    JavaScript is commonly used to perform this validation.
                </p>

                <h3>Purpose of Validation</h3>

                <ul>
                    <li>Prevents incorrect data from being submitted.</li>
                    <li>Provides immediate feedback to the user.</li>
                    <li>Improves the user experience.</li>
                    <li>Reduces unnecessary requests to the server.</li>
                </ul>

                <h3>JavaScript Event Handling</h3>

                <p>
                    JavaScript can use events such as
                    <b>submit</b>, <b>click</b>, <b>input</b> and
                    <b>change</b> to validate information.
                </p>

                <h3>Regular Expressions</h3>

                <p>
                    Regular expressions, also called RegEx, are patterns used
                    to check whether input follows a particular format.
                    They can be used to validate email addresses, phone numbers,
                    passwords and other inputs.
                </p>

                <h3>Validation Example</h3>

                <div class="form-demo">

                    <form id="validationForm">

                <h3>Improving Usability and Security</h3>

                <p>
                    Validation messages should clearly explain the error.
                    Input fields should have labels and suitable placeholders.
                    However, client-side validation alone is not sufficient for
                    security. The server must also validate and sanitize all
                    submitted data.
                </p>

            <h2>Question 3 – CSS Box Model and Positioning</h2>

            <div class="answer">

                <h3>CSS Box Model</h3>

                <p>
                    The CSS Box Model describes how every HTML element is
                    represented as a rectangular box.
                </p>

                <p>
                    It consists of four main components:
                </p>

                <ol>
                    <li><b>Content</b> – The actual text or elements.</li>
                    <li><b>Padding</b> – Space between content and border.</li>
                    <li><b>Border</b> – A boundary surrounding the padding.</li>
                    <li><b>Margin</b> – Space outside the border.</li>
                </ol>

                <h3>Box Model Example</h3>

                <div class="box-model-demo">
                    Content Area
                    <br>
                    Padding + Border + Margin
                </div>

                <h3>CSS Positioning</h3>

                <p>
                    CSS positioning controls where elements appear on a webpage.
                    Common positioning methods include:
                </p>

                <ul>
                    <li><b>Static</b> – Default position.</li>
                    <li><b>Relative</b> – Moves relative to its normal position.</li>
                    <li><b>Absolute</b> – Positioned relative to a positioned ancestor.</li>
                    <li><b>Fixed</b> – Stays fixed relative to the browser window.</li>
                    <li><b>Sticky</b> – Behaves like relative and becomes fixed while scrolling.</li>
                </ul>

                <h3>Why Does a Layout Break?</h3>

                <ul>
                    <li>Fixed-width elements.</li>
                    <li>Images larger than their containers.</li>
                    <li>Incorrect margins or padding.</li>
                    <li>Improper positioning.</li>
                    <li>Content overflowing the screen.</li>
                    <li>Missing media queries.</li>
                </ul>

                <h3>Using Media Queries</h3>

                <p>
                    Media queries allow different CSS rules to be applied
                    depending on the screen size. For example, the layout
                    can change from three columns on a desktop to one column
                    on a mobile phone.
                </p>

                <h3>Best Practices</h3>

                <ul>
                    <li>Use <b>box-sizing: border-box</b>.</li>
                    <li>Prefer flexible widths.</li>
                    <li>Use Flexbox or Grid for layouts.</li>
                    <li>Avoid unnecessary fixed positioning.</li>
                    <li>Use responsive images.</li>
                    <li>Test the website on different screen sizes.</li>
                </ul>

            </div>

        </section>

            <h2>Question 4 – DOM and Dynamic Content</h2>

            <div class="answer">

                <h3>What is the DOM?</h3>

                <p>
                    DOM stands for <b>Document Object Model</b>. It represents
                    an HTML document as a tree of objects. JavaScript can
                    access and modify these objects to dynamically change
                    webpage content.
                </p>

                <h3>Role of DOM</h3>

                <p>
                    The DOM allows JavaScript to modify HTML elements,
                    attributes, styles and text without requiring the entire
                    webpage to reload.
                </p>

                <h3>JavaScript DOM Manipulation</h3>

                <p>
                    JavaScript can select an HTML element using methods such as
                    <b>getElementById()</b> and then change its content using
                    <b>textContent</b> or <b>innerHTML</b>.
                </p>

                <h3>Dynamic Content Example</h3>

                <div class="dom-demo">

                    <div id="dynamicText">
                        Original Text
                    </div>

                    <button onclick="changeText()">
                        Change Text
                    </button>

                    <button onclick="changeColor()">
                        Change Style
                    </button>

                    <button onclick="resetText()">
                        Reset
                    </button>

                </div>

                <h3>Performance Improvements</h3>

                <ul>
                    <li>Modify only the required DOM elements.</li>
                    <li>Avoid unnecessary DOM updates.</li>
                    <li>Use event delegation when appropriate.</li>
                    <li>Minimize repeated DOM queries.</li>
                    <li>Load JavaScript efficiently.</li>
                </ul>

                <h3>User Experience Improvements</h3>

                <p>
                    Dynamic updates make websites faster and more interactive.
                    For example, shopping carts, search suggestions,
                    notifications and live data can be updated without
                    refreshing the entire webpage.
                </p>

        /* =========================================
           QUESTION 2 - FORM VALIDATION
        ========================================== */

        const form = document.getElementById("validationForm");

        form.addEventListener("submit", function(event) {

            event.preventDefault();

            const email = document.getElementById("email").value.trim();
            const phone = document.getElementById("phone").value.trim();

            const message = document.getElementById("validationMessage");

            /*
                Regular expression for email
            */
            const emailPattern =
                /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

            /*
                Regular expression for Indian-style
                10 digit phone number
            */
            const phonePattern =
                /^[6-9][0-9]{9}$/;


            if (!emailPattern.test(email)) {

                message.textContent =
                    "❌ Please enter a valid email address.";

                message.style.color = "red";

                return;
            }


            if (!phonePattern.test(phone)) {

                message.textContent =
                    "❌ Please enter a valid 10-digit phone number.";

                message.style.color = "red";

                return;
            }


            message.textContent =
                "✅ All inputs are valid!";

            message.style.color = "green";

        });


        /* =========================================
           QUESTION 4 - DOM MANIPULATION
        ========================================== */

        function changeText() {

            const text =
                document.getElementById("dynamicText");

            text.textContent =
                "The content was changed using JavaScript!";
        }


        function changeColor() {

            const text =
                document.getElementById("dynamicText");

            text.style.color = "blue";
            text.style.fontSize = "25px";
        }


        function resetText() {

            const text =
                document.getElementById("dynamicText");

            text.textContent = "Original Text";
            text.style.color = "black";
            text.style.fontSize = "20px";
        }

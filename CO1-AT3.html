Question 1 – Video Embedding

Data Snippet

A. <media>
B. <video src="video.mp4" controls></video>
C. <movie>
D. <vid>

Answer: B. <video>

The <video> tag is the official HTML5 element used to embed videos. It supports controls such as Play, Pause, Volume, and Full Screen. For the E-Learning Portal, lecture videos can be displayed using the <video> element.

Question 2 – Form Submission 

A. GET

B. POST

C. PUT

D. DELETE

Answer: POST

Students register using personal information such as name and email. POST securely sends data inside the request body. GET exposes data in the URL. Therefore POST is the correct method.

Question 3 – Semantic Navigation 

A. <div>

B. <nav>

C. <section>

D. <header>

Answer: <nav>

The navigation menu of the E-Learning Portal contains links such as Home, Courses, Assignments, Contact. The semantic HTML element used is <nav> because it clearly defines navigation links.

Question 4 – XML Syntax 

A. <note><to>User</to><from>Admin</from>

B. <note><to>User</to><from>Admin</from></note>

C. <note><to>User</from></note>

D. <note to="User"></note

Answer: B

Explanation

  • A → Missing closing </note> tag.
  • B → Correct XML syntax.
  • C → Closing tags do not match.
  • D → Closing bracket is missing.
Question 5 – Web Communication Protocol 

A. FTP

B. HTTP

C. SMTP

D. SNMP

Answer: HTTP

The browser communicates with the E-Learning Portal server using HTTP. HTTP transfers web pages, CSS, JavaScript and multimedia. FTP is for file transfer. SMTP is for email. SNMP is for network management.
